Event Handling adalah mekanisme dalam pemrograman untuk mendeteksi dan merespons aksi atau kejadian (*event*) yang dipicu oleh pengguna maupun sistem. Contoh kejadian tersebut meliputi penekanan tombol (*click*), pengiriman formulir (*submit*), pengetikan keyboard (*input/keyup*), atau pergerakan kursor mouse.

Karena PHP merupakan bahasa pemrograman **Server-Side** (berjalan di web server), sedangkan aksi klik mouse terjadi di sisi **Client-Side** (browser pengguna). PHP hanya akan memproses data setelah browser mengirimkan permintaan HTTP ke server. Untuk menangani reaksi instan klik mouse di browser tanpa *reload*, kita menggunakan JavaScript.

Atribut method="post" berfungsi untuk mengirimkan data formulir ke server secara tersembunyi melalui *HTTP Request Body* (tidak ditempel pada URL). Metode ini lebih aman untuk data sensitif, mendukung kapasitas payload yang besar, dan tidak memiliki batasan panjang URL.

Metode GET
  • Data terlihat di URL browser
  • Terbatas panjangnya (~2048 karakter)
  • Dapat di-bookmark / disimpan
  • Cocok untuk filter / pencarian
Metode POST
  • Data tersembunyi di HTTP Body
  • Kapasitas data besar (termasuk file)
  • Tidak dapat di-bookmark
  • Cocok untuk formulir & login

Berfungsi untuk mendeteksi jenis metode HTTP yang digunakan saat mengakses atau mengirim permintaan ke halaman web (misalnya GET atau POST). Hal ini berguna untuk memastikan kode pemrosesan formulir hanya dijalankan jika formulir telah dikirim.

Fungsi htmlspecialchars() digunakan untuk mengubah karakter khusus HTML (seperti <, >, &) menjadi entitas teks aman. Ini bertujuan mencegah serangan celah keamanan **Cross-Site Scripting (XSS)** agar skrip jahat yang dimasukkan pengguna tidak dieksekusi oleh browser.
